# Structure-Borne Sound

These are some [jupyter](https://jupyter.org/) notebooks that serve as interactive lecture notes for the course on structure-borne sound ("Körperschall") at TU Berlin. 

To use them online, follow the link to a dedicated jupyterlite site [here](https://esarradj.github.io/jl-sbs/notebooks/?path=sbs%2Findex.ipynb). This is recommend to get started quickly without any installation. The notebooks will then live in your browser and you can run the code directly there.

To use them offline, locally, clone or copy the repository including all files to your computer. You will need a [Python 3](https://python.org) installation with the necessary packages installed. The easiest way to get started is to install [uv](https://docs.astral.sh/uv/getting-started/installation/) and then run the notebooks from your shell with

```bash
uv run jupyter notebook index.ipynb
```
